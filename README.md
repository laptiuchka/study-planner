# Study Planner

Лабораторна робота №8. 
**Тема:** React Fundamentals: компоненти, JSX, props, стан, події та списки.

## Функціонал
- Додавання нових навчальних завдань.
- Зміна стану завдання (виконано / в процесі).
- Видалення завдань.
- Фільтрація списку (всі, невиконані, виконані).
- Сортування за пріоритетом.
- Підрахунок загальної статистики.

## Технології
- React (Vite)
- TypeScript
- CSS (за методологією BEM)
- ESLint
